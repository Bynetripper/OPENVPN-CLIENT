✨ Features:
• One-click installation of OpenVPN + Easy-RSA
• Automated server setup with PKI generation
• Client credential generation with inline certificates
• Import and connect using existing .ovpn files
• Beautiful dark mode interface
• Thread-safe async command execution
• Real-time activity logging
• Supports both certificate-only and username/password authentication
